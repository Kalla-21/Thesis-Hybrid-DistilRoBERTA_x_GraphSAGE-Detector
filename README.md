# Thesis-DistilRoBERTa-GraphSAGE-Hybrid-Model

The study aims to utilize a Hybrid model of DistilRoBERTa (textual analysis) and GraphSAGE (relational analysis) to classify a collection of information about online job offers (job listings) as legitimate or fraudulent/scam; moreover it aims to evaluate how these models perform in relation to their standalone counterparts in this context. The dataset is the EMSCAD Job Listing dataset with over 17,886 records and only 800+ being labelled as scams to simulate real life possibilities of a malicious online job listing to surface. This leads to a heavily skewed dataset where only <5% is trying to be properly classified hence the researchers ought to focus on prioritizing F1 score and MCC as the main metrics to evaluate the performance of a cross-attention model along with a late-fusion model in comparison to a standalone model of DistilRoBERTa and GraphSAGE.
